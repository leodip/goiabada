Guten Tag {{.name}},

Bei der Anmeldung an Ihrem Konto bei {{ .appName }} wurde einer Ihrer Wiederherstellungscodes anstelle eines Codes aus Ihrer Authenticator-App verwendet. Jeder Wiederherstellungscode funktioniert nur einmal, dieser also nicht mehr. {{if eq .remaining 0}}Sie haben keine unbenutzten Wiederherstellungscodes mehr.{{else if eq .remaining 1}}Sie haben noch 1 unbenutzten Wiederherstellungscode.{{else}}Sie haben noch {{ .remaining }} unbenutzte Wiederherstellungscodes.{{end}}

Falls Sie das selbst waren und Ihre Authenticator-App nicht mehr haben, deaktivieren Sie in Ihren Kontoeinstellungen die Zwei-Faktor-Authentifizierung und richten Sie eine neue Authenticator-App ein. Dazu wird ein neuer Satz Wiederherstellungscodes erstellt. Haben Sie die App noch, können Sie dort einen neuen Satz Wiederherstellungscodes erstellen, bevor Ihnen die Codes ausgehen.

Andernfalls kennt möglicherweise jemand Ihr Passwort und hat Ihre Wiederherstellungscodes. Wählen Sie auf der Anmeldeseite über „Passwort vergessen?“ ein neues Passwort, melden Sie sich dann an, deaktivieren Sie die Zwei-Faktor-Authentifizierung und richten Sie eine neue Authenticator-App ein. Sie können sich auch an Ihre Administration wenden.
