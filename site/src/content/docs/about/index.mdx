This page tells you why Goiabada exists, where its name comes from, and how to reach the people behind it.

Goiabada is an auth server you run yourself, made to be easy to set up and easy to live with. There are plenty of alternatives; this is one person's take on how it should work.

It's free and open source, and it'll stay that way. You host it, so the code and the data are yours.

## The name

Goiabada is a Brazilian sweet made from guava. It also starts with "Go", the language Goiabada is written in. 😉

![A block of goiabada, the Brazilian guava sweet](/img/about1.png)

## Who makes it

**Leonardo D'Ippolito** created Goiabada and maintains it, with fixes and ideas from the people who use it. You can join them: see [Contributing](/about/contributing/).

- **A security vulnerability:** email [contact@leodip.com](mailto:contact@leodip.com), as [Report a vulnerability](/reference/security/#report-a-vulnerability) describes.
