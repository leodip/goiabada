This page tells you where to reach the people behind Goiabada.

## Get in touch

- **A bug or a feature request:** open an issue on [GitHub](https://github.com/leodip/goiabada/issues), so everyone can follow it.
- **A security vulnerability:** email [contact@leodip.com](mailto:contact@leodip.com), as [Report a vulnerability](/reference/security/#report-a-vulnerability) describes.
- **Anything else:** email [contact@leodip.com](mailto:contact@leodip.com), or find Leonardo on [LinkedIn](https://www.linkedin.com/in/leodip/).

<Aside type="danger">
**Never** report a vulnerability in a public GitHub issue. Anyone can read it there, before there's a fix.
</Aside>

## Help with your project

Leonardo D'Ippolito, who makes Goiabada, is available for freelance work:

- **Goiabada:** integrating it with your apps, deploying it, or building a feature you need.
- **Full-stack development:** .NET, Go, Vue.js and JavaScript.
- **Infrastructure:** Docker, Kubernetes and SQL databases.
- **Software in general:** architecture, implementation and performance.

Email [contact@leodip.com](mailto:contact@leodip.com) to talk about your project.
